# M-Play for Android: releases

Downloads for **M-Play**, a personal video + music player for Android with a one-tap
**Video ⇄ Music** switch. This repository only holds the APK releases; the source is private.

## Install

1. On your phone, open the [latest release](https://github.com/mayo3030/Y-tube-releases/releases/latest)
   and download **M-Play.apk**.
2. Open the file. If Android asks, allow your browser to **install unknown apps**.
3. Open **M-Play**.

## Update

Inside the app: **Settings → App → Check for updates**, or tap **Update** on the banner
that appears at the top when a new version is out. The app checks `version.json` in this
repository, downloads the APK, verifies its SHA-256, and opens Android's installer. Android
only installs an update signed with the same key as the version you have.

## Notes

- Video plays through YouTube's official embedded player.
- Signing in is optional, and happens on Google's own sign-in page. Your session stays on
  your phone.
- Not affiliated with YouTube or Google.
